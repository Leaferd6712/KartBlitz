# Design references

`reference-images/` contains the original UI inspiration images, now named `ui-reference-*.webp` and `warped-kart-racers-reference-*.jpg`. Source URLs are in `reference-images/reference-links.txt`.

These are inspiration, not assets loaded by the game. Actual interface assets are in `ui/`; documentation screenshots are in `docs/assets/`. Original filenames are preserved in `docs/repository-file-moves.json`.
