KartBlitz online mode

Server-authoritative simulation on a Cloudflare Durable Object. All browsers predict locally and interpolate remotes from a compact binary snapshot stream.

60 HzDO physics (Alarm tick)
30 HzBinary snapshots + inputs
~60–120 msAdaptive remote delay
6Players per room

Lobby “host” is admin only (settings / start / return). Physics no longer runs in any player’s browser, so a host tab hitch does not freeze the race. Open with ?netDebug=1 for live delay / bandwidth HUD.

Lag reductions shipped

Payload

30 Hz snapshots/inputs, quantized binary pose, cold fields on change / every 16 ticks.

Interpolation

Delay tracks measured jitter (~60–200 ms). Extrapolate ≤50 ms instead of freezing remotes.

Authority

Physics on the Worker room. Admin sends baked track once at startRace.

Reconcile

Error-weighted exponential blend; hard snap only on large error or launch.
