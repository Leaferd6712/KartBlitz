# Player experience pass

The 25 changes in this pass map to the earlier review, using the existing purple slate, gold and mint identity.

1. **Touch spacing:** steering, pedals and action buttons have separate short-landscape areas; the secondary position list yields to controls.
2. **Welcome:** a single short welcome replaces the forced patch-note/device sequence. Patch notes remain optional.
3. **Quick Race:** easy AI, three rivals, one lap, dry weather, medium tyres and launch assistance; saved custom-race choices remain intact.
4. **Portrait menu:** the action panel appears before the car showcase, putting play near the top.
5. **Focused setup:** tuning is optional in Custom Race and hidden when Time Trial equalises it.
6. **Driving guide:** an optional live practice guide advances through movement, steering, braking and Boost from real input.
7. **Launch clarity:** countdown driving reminders and a forgiving Quick Race launch; skill launches remain in custom modes.
8. **Guest practice:** local play starts without a username gate; pit exit messages point towards the exit. Cloud registration remains available from the leaderboard.
9. **Readable scaling:** text controls and canvas HUD respond to the UI-size setting.
10. **Settings:** consistent panels, ranges, spacing and readable help text.
11. **Player-first navigation:** admin, patch notes and advanced tools are secondary; save conflicts/errors remain visible.
12. **Plain ability names:** Boost and Zone in primary controls, with detailed ERS/DRS explanations in help.
13. **Tyre guidance:** recommendations and Time Trial's no-wear explanation instead of irrelevant lifespan estimates.
14. **Your kart:** a mint outline, Boost highlight and YOU/position labels distinguish the player.
15. **Minimap:** directional player marker, contrasting opponents and an unobstructed short-touch position.
16. **Circuit identity:** scenery culling uses the actual render target so cached trees and trackside details can appear correctly.
17. **Consistent car:** the local procedural showroom model derives from the race car's geometry and part colours; a static fallback keeps play available.
18. **Track cards:** scenery previews, readable targets and visible names for locked circuits.
19. **Ability feedback:** charge/active states and on-track Zone availability get clearer labels and cues.
20. **Motion:** short screen transitions, restrained showroom motion and respect for reduced-motion preferences.
21. **Safe navigation:** leave/restart confirmations, resume on cancellation, and sound/help in the pause menu.
22. **Positive results:** personal bests get a clear headline and improvement comparisons; practice is framed as progress.
23. **Welcoming garage:** free paint opens first, the active tab matches its content, and a first-upgrade goal explains rewards. Portal-only ads stay off the standalone game.
24. **Audio cues:** distinct synthesised tones for ability activation, readiness and empty charge, following volume/mute settings.
25. **Resilient assets:** bundled fonts/preview, portal-only SDK loading, preview fallback, and one explicit runtime manifest for browser/desktop builds.

Automated player checks cover first launch/return visits, guest practice, Quick Race preset isolation, Time Trial setup, scale and touch hit-area separation. Existing suites exercise accessibility, progression, AI racing, results and persistence. README captures show real menu, garage, keyboard and touch play; desktop checks cover offline boot/racing and persistence across launches.
