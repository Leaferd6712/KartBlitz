# Project commands

Use the named commands in the root `package.json`; their `npm run` names are unchanged.

- `ai-training/`: starting and researching AI policies, coaching, exports and browser comparisons.
- `build/`: preparing browser/desktop assets, exporting tracks and checking shipped files.
- `testing/`: test runners.
- `leaderboards/`: leaderboard backup, recording export and seed utilities.
- `development/`: local test HTTP server and documentation screenshots.
- `release/`: release checksum generation.

The two simulator builders and campaign browser checker keep their original root paths for existing compatibility checks. [Repository file guide](../FILE-GUIDE.md).
